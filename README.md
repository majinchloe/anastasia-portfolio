# Anastasia’s Portfolio — Homepage Prototype V2

Open `index.html` in your browser. No installation or build step needed.

## Changes in V2
- New illustrated A monogram PNG in `assets/` and header title “ANASTASIA’S PORTFOLIO”.
- Desktop sunset scene extends to right screen edge and gradually fades into the copy on the left.
- Subtle paper grain texture.
- Dramatic independent left-right mountain movements, vertical sun float, waving cat tail, double blinks.
- Footer has three overlapping mountain wave layers and texture; removed the decorative flower.
- Pointer parallax, reduced-motion setting and responsive layout preserved.

## Still prototype
Portfolio cards are placeholders, other pages and forms are not built. Contact links are intentionally not configured.

## Deploy
Commit the unzipped contents to a GitHub repository (root containing index.html) and connect it to Cloudflare Pages. Build command: none; output directory: `/`.
Google Drive can hold project versions and artwork, but it does not deploy or synchronise changes to Cloudflare Pages. GitHub should be the canonical website source.


Cloudflare Pages: auto-deploy from the `main` branch. Preview site: https://anastasia-portfolio-bb4.pages.dev/
